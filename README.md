# imger
a rapid image viewer with cache. 

默认快捷键如下:

修改配置: F10

下一张图片: x, Ctrl+→

上一张图片: z, Ctrl+←


视线向上(1/8屏幕): ↑

视线向下(1/8屏幕): ↓

视线向左(1/8屏幕): ←

视线向右(1/8屏幕): →

视线向上(1像素): Shift+↑

视线向下(1像素): Shift+↓

视线向左(1像素): Shift+←

视线向右(1像素): Shift+→


放大(缩放倍率+25%, 最高1000%): +, Shift++

缩小(缩放倍率-25%, 最低5%): -

原始大小: =
